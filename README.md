# mwanachama-backend-compute

A Go library that evaluates the functions an agency defines and publishes.

## What it is not

- Not a scheduler.
- Not a workload runner.
- No database.
- No HTTP.
- No imports from any other mwanachama repo.

## Status

The package is empty so far. There is no release tag yet. The repo is local and not yet pushed to GitHub.

## Build and test

```
make build
make test
```
